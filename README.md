# nerd-erp

Public ERP frontend sandbox focused on React, TypeScript, dashboard workflows, and Arabic-first product experiments.

This repository is a public engineering workspace for exploring ERP-oriented frontend patterns: admin interfaces, reporting surfaces, operational flows, and product structure for business software.

## Focus areas

- React and TypeScript frontend work
- ERP dashboards and admin views
- Operational product flows
- Arabic-first UI and RTL considerations

## Status

- Public sandbox repository
- Useful for product-direction and frontend implementation work
- Not presented here as a production deployment
